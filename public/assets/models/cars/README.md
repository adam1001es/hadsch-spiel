# Autos (Lebensspiel)

Quelle: „Generic passenger car pack“ von **Comrade1280**, https://skfb.ly/6sUFy, Lizenz **CC BY 4.0**
(http://creativecommons.org/licenses/by/4.0/). Erfundene Modelle ohne echte Marken/Logos.

Bearbeitung: in 10 einzelne Autos zerlegt, Front nach **+z**, Boden bei y = 0, Mitte bei x = z = 0, Texturen auf 512 px verkleinert.
Jedes Auto: Gruppe `body` + vier Räder `wheel_fl`, `wheel_fr`, `wheel_rl`, `wheel_rr` (f/r = vorne/hinten, l/r = links/rechts),
Drehpunkt jeweils in der Radmitte → Räder drehen sich um ihre x-Achse, Vorderräder lenken um y.
