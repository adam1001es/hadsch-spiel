# Aufnahmen der arabischen Gebete und Ayat

Arabische Texte erklingen im Spiel **nur als echte Aufnahme**, nie als Computerstimme.
Sobald eine Datei hier liegt, erscheint im Spiel automatisch ein ▶-Knopf neben dem Text
(und sie spielt automatisch, wenn „Arabische Gebete automatisch abspielen“ eingeschaltet ist).

So aufnehmen: iPhone-App „Sprachmemos“, ruhiger Raum, Handy ca. 20 cm vor dem Mund,
langsam und deutlich, jeder Text einzeln, ca. 1 Sekunde Stille am Anfang und Ende.
Als MP3 (oder M4A, dann wandle ich sie um) mit genau diesen Dateinamen:
